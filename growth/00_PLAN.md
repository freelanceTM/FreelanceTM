# FreelanceTM — GROWTH PLAN (Concierge MVP)

**Owner:** Founder. **Mode:** Manual deals first. **No backend code for 30 days.**

## Decisions (locked, override if you disagree)
- **Niche:** Reels/TikTok editing for small businesses (cafes, shops, salons, local brands).
- **Why this niche:** daily demand, 1–2 day delivery, repeat orders, easy to QA, cheap to start.
- **Commission:** 10% (code currently 20% — change later, one number).
- **Avg ticket assumption:** 70 AZN (tune in `01_unit_economics.md`).
- **Payment:** money flows through YOU (card/bank transfer). You pay editor minus 10%.
- **Channel:** Telegram + Instagram DMs + niche chats. Personal outreach, not "we have a platform".

## The only goal for Week 1
**Close 5 real paid orders by hand.** That is more valuable than all of F-1…F-11.

## North-star funnel (track weekly)
Outreach msgs → Replies → Deals closed → GMV → Commission (10%) → Repeat orders.

## What's in this folder
- `00_PLAN.md` — this file

- `03_demand_script.md` — get clients (cold DM scripts)
- `04_offer_landing.html` — one-page offer (send the link / screenshot)
- `05_deal_tracker.csv` — track every deal by hand
- `06_objections.md` — kill the top objections
- `07_7day_checklist.md` — do this, in order

## Hard rules
1. No new backend features until a deal is blocked by a missing feature.
2. Every day ends with: how many outreach msgs sent, how many replies, how many AZN.
3. If you're coding, you're avoiding selling. Stop.
